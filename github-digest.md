# GitHub Digest

Current setup and architecture: [README.md](README.md) and [github-digest.map.md](github-digest.map.md).

This personal triage dashboard covers direct review requests, team reviews, authored and assigned-agent PRs, previously engaged PRs, and GitHub activity. It keeps pins, archive/delete, set-aside, notes, filters, and notification state in the browser. It does not post reviews, comments, or merge PRs.

The original single-file implementation and historical specification remain in Git history.
