GitHub Digest — Setup

This dashboard reads your GitHub PRs directly. To do that it needs a Personal Access Token.

  1. Go to github.com/settings/tokens/new
  2. Name it something like "PR Digest"
  3. Select scopes: repo, read:org, notifications
  4. Generate, copy, and paste below
